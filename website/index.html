Otwórz ticket jak klient

To symulacja serwera z prawdziwymi tekstami bota. Wybierz kategorię z menu, wyślij formularz, przejmij ticket jako obsługa i zamknij go. Bilet w tle drukuje się na nowo z Twoim numerem.

Droga ticketu

  1. Klient wybiera kategorię z menu panelu
  2. Wypełnia formularz z pytaniami tej kategorii
  3. Bot tworzy prywatny kanał i oznacza obsługę
  4. Ktoś z obsługi klika Przejmij
  5. Zamknięcie z potwierdzeniem, transkrypt trafia na logi
  6. Klient dostaje DM i ocenia obsługę
W zestawie

Wszystko, czego potrzebuje sklep

Bez bazy danych i bez panelu w przeglądarce. Stan ticketu bot zapisuje w temacie kanału, a całą konfigurację zmieniasz w jednym pliku config.js.

Panel

Menu kategorii

Zakup, Pomoc, Reklamacja, Partnerstwo i Odbiór nagrody. Każda z własną emotką i opisem, dodasz kolejne w configu.

Formularz

Pytania przed startem

Do pięciu pól na kategorię. Odpowiedzi lądują w pierwszej wiadomości ticketu, więc obsługa od razu wie, o co chodzi.

Uprawnienia

Prywatny kanał

Kanał w stylu 🛒・zakup-nick widzi tylko klient, bot i role supportu. Limit otwartych ticketów na osobę.

Obsługa

Przejmij i dodaj

Przycisk Przejmij pokazuje, kto prowadzi rozmowę. Komendami dodasz lub usuniesz osobę i zmienisz nazwę kanału.

Archiwum

Transkrypty .txt

Pełny zapis rozmowy z embedami i załącznikami trafia na kanał logów oraz do wiadomości prywatnej klienta.

Opinie

Oceny 1–5 gwiazdek

Po zamknięciu klient ocenia obsługę jednym kliknięciem w DM. Każda ocena pojawia się na logach z numerem ticketu.

Komendy

Pięć komend i gotowe

Komendy rejestrują się same przy starcie bota. Działają tylko tam, gdzie mają sens: komendy /ticket wyłącznie w kanale ticketu.

/panelWysyła panel ticketów na bieżący kanaładmin
/ticket dodajDodaje osobę do ticketuobsługa
/ticket usunUsuwa osobę z ticketu (poza właścicielem)obsługa
/ticket nazwaZmienia nazwę kanału ticketuobsługa
/ticket zamknijZamyka ticket z opcjonalnym powodemklient i obsługa

Instalacja

# 1. pobierz kod i zależności $ git clone -b claude/discord-bot-tickets-ldljd0 \ https://github.com/kamiljagiello707-dotcom/Disocrd-bot-.git $ cd Disocrd-bot- && npm install # 2. token i ID w pliku .env $ cp .env.example .env # 3. uzupełnij src/config.js, potem start $ npm start
  • W panelu deweloperskim włącz Server Members Intent.
  • W config.js wpisz ID kategorii, kanału logów i ról supportu.
  • Rola bota musi stać wyżej niż role obsługi.
  • Na wybranym kanale wpisz /panel.
Node.js 18+
