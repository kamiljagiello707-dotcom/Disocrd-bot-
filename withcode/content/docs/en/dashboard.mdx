# Dashboard and permissions

## Who has access

A server dashboard is available to:

1. the server owner,
2. people with the **Administrator** or **Manage Server** permission,
3. roles and users added in the **Dashboard access** tab (_View_ or _Edit_ level).

Permissions are checked **on the server on every save** — hiding a button in the UI is just a convenience.

## Unsaved changes

When you change something, a **You have unsaved changes** bar appears with **Save** and **Revert** buttons. Leaving the page with unsaved changes asks for confirmation.

## Audit log

The **Audit log** tab shows who changed what and when — with before and after values.
