# Introduction

WithBot is a moderation bot for Discord. It protects your server from spam, raids and toxic messages, and you change every setting in the WithCode.pl dashboard.

## What WithBot does

- **AutoMod** — six filters: anti-spam, anti-link, anti-invite, word filter, anti-caps, anti-mention.
- **Anti-raid** — detects a wave of new accounts and triggers a lockdown.
- **Cases and punishments** — warnings, timeouts and bans with history and automatic thresholds.
- **Logs, verification, reaction roles, greetings and tickets.**

## How it works

The bot reacts to Discord events in real time. Configuration is stored in the database and the bot applies changes within a second of saving them in the dashboard.

> Slash commands always work. Text commands require the prefix set in the dashboard (`!` by default).
