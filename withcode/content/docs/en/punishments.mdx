# Warnings and punishments

Every moderation action is a **case** with a number, reason, moderator and duration.

## Automatic thresholds

In the **Auto punishments** tab you can set escalation, e.g.:

| Warnings | Action        |
| -------- | ------------- |
| 3        | 1 h timeout   |
| 5        | 1 day timeout |
| 7        | Ban           |

Only **active** (not revoked) warnings count.

## Revoking

Open a case in the dashboard and click **Revoke punishment**. The bot lifts the timeout or ban on Discord and records who revoked it and when.

## Export

The cases table exports to CSV using the current filters.
