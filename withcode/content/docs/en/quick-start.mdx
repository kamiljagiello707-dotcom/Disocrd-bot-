# Quick start

## 1. Add the bot

Click **Add to Discord** and pick a server. You need the **Manage Server** permission.

## 2. Position the bot role

In server settings, move the **WithBot** role above the roles the bot should manage (e.g. roles granted by verification).

## 3. Open the dashboard

Sign in with Discord on WithCode.pl and choose your server. We recommend starting with:

1. Enabling **Anti-spam** and **Anti-invite** (on by default).
2. Setting a log channel in the **Logs** tab.
3. Adding a punishment threshold, e.g. `3 warnings → 1 h timeout`.

## 4. Check it works

```text
/automod status
/ping
```

The bot replies with the list of active modules and its latency.
