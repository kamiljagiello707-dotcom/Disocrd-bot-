# Szybki start

## 1. Dodaj bota

Kliknij **Dodaj do Discorda** i wybierz serwer. Potrzebujesz uprawnienia **Zarządzanie serwerem**.

## 2. Ustaw rolę bota

W ustawieniach serwera przesuń rolę **WithBot** nad role, którymi bot ma zarządzać (np. role nadawane w weryfikacji).

## 3. Otwórz panel

Zaloguj się przez Discord na WithCode.pl i wybierz serwer. Na start polecamy:

1. Włączyć **Anty-spam** i **Anty-zaproszenia** (domyślnie aktywne).
2. Ustawić kanał logów w zakładce **Logi**.
3. Dodać próg kar, np. `3 ostrzeżenia → timeout 1 h`.

## 4. Sprawdź działanie

```text
/automod status
/ping
```

Bot odpowie listą aktywnych modułów i swoim opóźnieniem.
